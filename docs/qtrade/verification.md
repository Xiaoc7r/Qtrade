浏览器操作实际覆盖：空数据提示 → 选择虚构数据并分析 → 调整估值维度重新计算 → 安装策略 → 创建模拟账户 → 打开并关闭绑定快照对话框。没有提交真实券商交易或调用收费模型。模拟执行的买卖点、T+1、费用、重复事件、重启与暂停等由复用模块的真实账本测试验证。

Windows 首次运行旧测试时，默认 GBK 编码导致测试临时策略不能按 UTF-8 加载；设置 `PYTHONUTF8=1` 后消除。另有三个原测试假定连续系统时钟必不同，Windows 粗粒度时钟下偶发并列；修改测试的时钟夹具，明确不同创建时刻，未改变生产撮合逻辑。

尚未验证：真实用户行情源、全 A 股覆盖/实时数据、生产市场下持续模拟收益、原生桌面重新打包、Docker 启动、QMT/XTP SDK、真实账号与报撤单。没有以样例回测宣称任何策略盈利。

源码发布时保留上游 CI；实际远端状态以 GitHub Actions 为准。旧 Docker 自动发布只对上游仓库或显式 workflow_dispatch 生效，Qtrade 首次源码推送不会顺带发布镜像。
